# 🌌 Morgane Maréchal — Developer Portfolio

A modern, responsive portfolio built with **React** and **Material UI**

## 🚀 Features

- 🎨 **Custom Material UI theme** (dark mode, tech style)
- 💡 **Glowing cursor halo** 
- 📱 **Fully responsive layout**
  - Sidebar navigation on desktop
  - Horizontal navigation on mobile
- ⚡ **Smooth scroll** navigation between sections
- 💻 **Tech-inspired typography** using *Space Grotesk* and *JetBrains Mono*
---

## 🛠️ Tech Stack

| Category | Technologies |
|-----------|---------------|
| Frontend Framework | [React] |
| UI Library | [Material UI (MUI)] |
| Fonts | [Space Grotesk], [JetBrains Mono] |
| Styling | CSS + MUI Theme System |
| Routing | [React Router DOM] |
